Learning problem and supervision¶

Input $d_i$ is description text only. Output $y_i\in\{0,1\}^{15}$ indicates which selected shelf labels meet the group's vote-share rule. A book may have several labels or none. This supports content tagging for discovery, rather than personalized user-item recommendation. We have no per-user interactions in this metadata file, so collaborative LFM/BPR is not a direct fit to this task.

After the fixed exclusions in the original repository, let $v_i$ be the sum of remaining shelf counts. Keep nonempty descriptions with $v_i\geq10$, and set $y_{ij}=\mathbf{1}[c_{ij}/v_i\geq0.10]$. Select the 15 most frequent positive shelves from the training partition only. Zero labels mean no selected shelf passes the heuristic, not that a human verified the absence of those genres. The inherited exclusion list still leaves some non-content shelves in the denominator; these are weak, noisy labels rather than a curated ontology. We retain manga as an observed shelf even though it describes a medium rather than a romance subgenre; the target is reader shelf usage.

def select_labels(df, train, k=15):
    """Select vocabulary only from training targets; no validation/test label peeking."""
    counts = Counter(name for d, v in zip(df['shelves'].iloc[train],
                                         df['votes'].iloc[train])
                     for name, count in d.items() if count / v >= .1)
    labels = [n for n, _ in counts.most_common(k)]
    if len(labels) != k:
        raise ValueError(f'Need {k} labels, found {len(labels)}')
    return labels

def make_targets(df, labels):
    return np.array([[d.get(s, 0) / votes >= .1 for s in labels]
                     for d, votes in zip(df['shelves'], df['votes'])], dtype=np.uint8)

Work-disjoint train, validation and test¶

Editions of the same work stay together. The original outer GroupShuffleSplit uses seed 0 and a 20% test fraction by work group. A second grouped split with seed 1 reserves 20% of the development works for validation. Because work sizes differ, row fractions are approximate. Vectorizers and classifiers fit on train; model choice and thresholds use validation; test is scored after selection is written to disk. A missing work ID would fall back to a per-book key; there were none in this full run.

We keep the model fitted on train after threshold selection. Refitting on train+validation could shift its score scale and invalidate these thresholds. The earlier plan's two-way split used more training books, so compare the matched ablations below rather than claiming a direct gain over that old run.

def split_books(df):
    """Preserve original outer split (seed 0); reserve 20% of development for val."""
    dev, test = next(GroupShuffleSplit(test_size=.2, random_state=0)
                     .split(df, groups=df['group']))
    ti, vi = next(GroupShuffleSplit(test_size=.2, random_state=1)
                  .split(df.iloc[dev], groups=df['group'].iloc[dev]))
    splits = {'train': dev[ti], 'validation': dev[vi], 'test': test}
    groups = {k: set(df['group'].iloc[v]) for k, v in splits.items()}
    assert not (groups['train'] & groups['validation'])
    assert not (groups['train'] & groups['test'])
    assert not (groups['validation'] & groups['test'])
    assert len(np.unique(np.concatenate(list(splits.values())))) == len(df)
    return splits

Text representation¶

Word TF-IDF uses unigrams and bigrams, 50,000 features, min_df=5, English stop-word removal and sublinear term frequency. A component is proportional to $(1+\log tf)\,[\log((1+n)/(1+df))+1]$, followed by L2 normalization. Vocabulary and IDF are fitted on training descriptions only.

The richer representation concatenates word features with up to 60,000 char_wb 3–5 character n-grams. Each block is normalized separately; fixed weights are 1.0 for words and 0.5 for characters. Character fragments can help with morphology, spellings and non-English text, at extra memory and runtime cost. Neither representation sees titles, authors, ratings, or shelf counts.

def make_features(kind):
    word = TfidfVectorizer(max_features=50_000, ngram_range=(1, 2), min_df=5,
                          stop_words='english', sublinear_tf=True,
                          dtype=np.float64)
    if kind == 'word':
        return word
    if kind != 'word_char':
        raise ValueError(kind)
    # Character fragments capture morphology, names, spelling, and non-English
    # descriptions. Each block is L2 normalized; weights are fixed in advance.
    char = TfidfVectorizer(analyzer='char_wb', ngram_range=(3, 5), min_df=5,
                          max_features=60_000, sublinear_tf=True, dtype=np.float64)
    return FeatureUnion([('word', word), ('char', char)],
                        transformer_weights={'word': 1., 'char': .5}, n_jobs=1)

Algorithms and objectives¶

One-vs-rest (OvR) fits one independent binary classifier per shelf. For label $j$, its linear score is $s_{ij}=w_j^Tx_i+b_j$ and $z_{ij}=2y_{ij}-1$. With intercept_scaling=1, liblinear also regularizes the synthetic intercept weight; write $\widetilde w=(w,b)$.

Logistic regression minimizes $\tfrac12\|\widetilde w_j\|_2^2+C\sum_i a_{ij}\log(1+\exp(-z_{ij}s_{ij}))$. LinearSVC minimizes the analogous L2-regularized squared hinge objective $\tfrac12\|\widetilde w_j\|_2^2+C\sum_i a_{ij}\max(0,1-z_{ij}s_{ij})^2$. Higher C weakens regularization relative to data fit. Balanced class weights are $a_{ij}=n/(2n_{j,y_{ij}})$, computed on training data for each OvR classifier.

LR is easy to interpret and supports sparse text efficiently. Its weighted sigmoid scores should not be treated as calibrated real-world probabilities. Linear SVM also scales to sparse features and emphasizes separation, but returns margins rather than probabilities. OvR does not explicitly model label dependencies; bag-of-ngrams cannot reliably capture long-range meaning. Training and prediction operate on sparse nonzeros rather than dense document vectors; prediction costs approximately $O(K\,nnz(X))$. The word+character model needs more nonzeros and K weight vectors of length 110,000 rather than 50,000. A nonlinear kernel matrix is unnecessary here.

def classifier(config, jobs):
    common = dict(C=config['C'], class_weight='balanced' if config['balanced'] else None,
                  random_state=0, max_iter=3000)
    base = (LogisticRegression(solver='liblinear', **common)
            if config['model'] == 'lr' else LinearSVC(dual='auto', **common))
    return OneVsRestClassifier(base, n_jobs=jobs)

Thresholds turn scores into labels¶

For a fitted classifier, predict $\widehat y_{ij}=\mathbf{1}[s_{ij}\geq t_j]$. We compare a default threshold 0, one global threshold maximizing validation micro-F1, and one threshold per label maximizing its validation F1. Independent per-label F1 optimization corresponds to maximizing the mean (macro-F1). It need not maximize micro-F1.

The implementation sorts each label's validation scores, updates cumulative TP, and evaluates F1 only at the end of a complete equal-score block. This costs $O(n\log n)$ per label. Ties keep the highest threshold; a label with no validation positives predicts none. We consistently use >=, including at inference. Threshold changes do not change AUC/AP because the scores and their rankings stay fixed. Thresholds are not tuned on test.

def best_f1_threshold(y, scores):
    """Exact F1 optimum among distinct score boundaries, using >= consistently.

    Whole equal-score blocks are considered together. On ties retain the
    highest threshold (fewest predicted positives). No-positive labels predict
    none; no validation labels or classifier probabilities are assumed here.
    """
    y, scores = np.asarray(y).ravel(), np.asarray(scores).ravel()
    if not len(y) or not np.isfinite(scores).all():
        raise ValueError('Need nonempty finite scores')
    if not y.sum():
        return float(np.nextafter(scores.max(), np.inf))
    order = np.argsort(-scores, kind='stable')
    s, truth = scores[order], y[order]
    ends = np.r_[np.flatnonzero(s[:-1] != s[1:]), len(s) - 1]
    tp = np.cumsum(truth, dtype=np.float64)[ends]
    f1 = 2 * tp / (ends + 1 + truth.sum())
    return float(s[ends[np.argmax(f1)]])

def tune_thresholds(y, scores):
    return np.array([best_f1_threshold(y[:, j], scores[:, j])
                     for j in range(y.shape[1])])

Held-out test ablations¶

Micro-F1 pools TP/FP/FN over book-label pairs, so frequent shelves matter more. Macro-F1 averages F1 equally across shelves and is our selection objective. ROC-AUC measures ranking of positives above negatives, while average precision (AP) adds a useful view when positives are rare. High AUC alone does not imply the chosen labels are accurate. Ordinary accuracy is uninformative with many negative targets.

The prior baseline returns training prevalences and thresholds them at 0.5. The literal keyword baseline detects the shelf name in the description after simple punctuation/space normalization. These have no fitted text model. Only the reference LR and the validation-selected candidate are scored on the original held-out test, under their predeclared threshold policies. We do not switch models based on this table. The global policy can produce higher test micro-F1 than the per-label policy; the primary configuration follows the validation macro-F1 criterion declared before test evaluation, rather than selecting the best-looking test row.

Work grouping does not remove all repeated descriptions across different IDs. This is a diagnostic, not a new deduplicated retraining experiment. Near duplicates, shared authors and shared series can remain. Random work splits do not establish temporal or new-author generalization.

Shelf alias decision and a separate target¶

Retain all 15 shelves for the primary group task. Historical and historical romance are related but not identical concepts, as are the contemporary and paranormal pairs. As sensitivity analysis, coarsen these three pairs to 12 labels by OR-ing their original binary targets. Do not sum vote counts: the same reader could use both shelves. This OR rule does not create positives merely because two individually sub-threshold counts add up to 10%.

Use the selected architecture, fit a new 12-output model on train and tune new thresholds on validation. The task and its target prevalences have changed; an F1 difference is not a direct model improvement on the original task.

def merge_targets(y, labels):
    """OR original positive indicators, without summing overlapping reader votes.

    This is a *different* coarser target; never compare its F1 as a direct gain
    on the unmerged 15-shelf task. No top-K reselection is performed.
    """
    names = list(dict.fromkeys(ALIASES.get(s, s) for s in labels))
    merged = np.zeros((len(y), len(names)), dtype=np.uint8)
    for j, s in enumerate(labels):
        merged[:, names.index(ALIASES.get(s, s))] |= y[:, j]
    return merged, names

Appendix: the actual training and selection loop¶

The following is the experiment driver's actual source, including feature fits, candidate fitting, validation threshold search and the selection freeze. It was executed by the full-data CLI run; this display is a code walkthrough and does not silently launch a second training run. The next part of the driver performs the separate merged task and only then scores test data.

training_source = inspect.getsource(run.main)
start = training_source.index("    validation_rows, bundles")
end = training_source.index("    # Separate coarser-label")
display(Code(training_source[start:end], language="python"))

    validation_rows, bundles = [], {}
    for kind in ('word', 'word_char'):
        print(f'Fitting {kind} features...', flush=True)
        vec, feature_start = make_features(kind), time.perf_counter()
        xtr = vec.fit_transform(df.description.iloc[tr])
        xva = vec.transform(df.description.iloc[va])
        feature_seconds = time.perf_counter() - feature_start
        joblib.dump(vec, art/f'vectorizer_{kind}.joblib', compress=1)
        print(f'Features {xtr.shape}, nnz={xtr.nnz:,}, {feature_seconds:.1f}s', flush=True)
        for config in [c for c in CANDIDATES if c['features'] == kind]:
            print('Training', config['name'], flush=True)
            t = time.perf_counter()
            clf = fit_checked(classifier(config, args.jobs), xtr, y[tr])
            scores = clf.decision_function(xva)
            train_seconds = time.perf_counter()-t
            variants = threshold_variants(y[va], scores)
            for policy, thresholds in variants.items():
                validation_rows.append({'candidate': config['name'], 'policy': policy,
                    **config, **metrics(y[va], scores, thresholds),
                    'train_seconds': train_seconds, 'feature_seconds': feature_seconds,
                    'n_features': xtr.shape[1]})
            bundle = {'classifier': clf, 'config': config, 'labels': labels,
                      'thresholds': variants['per_label'], 'threshold_variants': variants}
            joblib.dump(bundle, art/(config['name']+'.joblib'), compress=1)
            bundles[config['name']] = bundle
            print({policy: round(metrics(y[va], scores, threshold)['macro_f1'], 4)
                   for policy, threshold in variants.items()}, flush=True)
            pd.DataFrame(validation_rows).to_csv(out/'validation_search.csv', index=False)
        del xtr, xva, vec
        gc.collect()

    search = pd.DataFrame(validation_rows)
    eligible = search[search.policy == 'per_label'].sort_values(
        ['macro_f1', 'micro_f1', 'candidate'], ascending=[False, False, True])
    winner_name = eligible.iloc[0]['candidate']
    winner = bundles[winner_name]
    decision = {'selection_metric': 'validation macro-F1, per-label thresholds',
                'secondary_tiebreak': 'validation micro-F1, then candidate name',
                'selected_candidate': winner_name,
                'selected_config': winner['config'],
                'selected_validation_macro_f1': float(eligible.iloc[0].macro_f1),
                'labels': labels, 'thresholds': winner['thresholds'].tolist(),
                'refit_on_train_plus_validation': False,
                'reason_no_refit': 'Keep validation-tuned thresholds on the fitted score scale.',
                'test_used_for_selection': False}
    # Persist the choice BEFORE scoring any held-out test description.
    write_json(out/'selection.json', decision)
    print('FROZEN SELECTION:', winner_name, flush=True)
    vec = joblib.load(art/f'vectorizer_{winner["config"]["features"]}.joblib')
    joblib.dump({**winner, 'vectorizer': vec}, art/'selected_model.joblib', compress=1)

Related sources and reproducibility¶

The official Goodreads dataset page describes the late-2017 public-shelf collection and the academic-use conditions. Wan and McAuley (2018), Item Recommendation on Monotonic Behavior Chains, study recommendation across ordered user behaviors. Wan et al. (2019), Fine-Grained Spoiler Detection from Large-Scale Review Corpora, study sentence-level spoiler detection. These provide dataset context; their task scores are not comparable to our description-to-shelf F1.

Implementation references: scikit-learn 1.6 documentation for text features, logistic regression, LinearSVC, threshold tuning, and metrics.

Reproduce from the repository root in the documented Python environment:

python -m scripts.download_romance
python -m unittest discover -s tests -v
python -m modeling.run --jobs 4
python -m scripts.build_modeling_report

Raw data and fitted artifacts stay local and are excluded from Git. The original code.py remains intact. The notebook and HTML embed all their outputs; the grader does not need to execute them. The shared group workbook still needs the other members' sections and must be rerun and exported after integration.
